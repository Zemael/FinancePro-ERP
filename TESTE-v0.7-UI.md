# FinancePro ERP v0.7 — Nova UI

## Alterações
- Design System central em `FinancePro.UI/Resources/FP.DesignSystem.xaml`.
- Nova interface do módulo Empresas.
- Cabeçalho com breadcrumb e ações.
- Cartões KPI.
- Área de filtros.
- DataGrid moderno.
- Painel lateral para consulta e edição.
- Recursos prontos para reutilização nos demais módulos.

## Teste
1. Abra `FinancePro.sln`.
2. Compile a solução.
3. Inicie sessão.
4. Abra **Empresas**.
5. Teste pesquisa, seleção, edição, criação e ativação/desativação.
