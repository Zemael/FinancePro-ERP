# FinancePro v6.70.0 — Nova identidade visual

O FinancePro passa a utilizar o novo logótipo fornecido pelo utilizador em toda a aplicação.

Foram preparadas variantes transparentes para o logótipo completo, símbolo compacto e ícone multirresolução. A identidade foi aplicada ao login, configuração inicial, menu lateral, janelas, executável, instalador e documentos comerciais impressos.
