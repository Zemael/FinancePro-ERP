# FinancePro v6.2.0 — Diário, Razão e Balancete

## Entregue
- Diário Geral com filtros por período, estado e pesquisa documental.
- Razão por conta com saldo inicial implícito e saldo acumulado.
- Balancete de verificação com saldos iniciais, movimentos e saldos finais.
- Validação de equilíbrio contabilístico.
- Exportação CSV para os três relatórios.
- Interface integrada ao módulo Contabilidade no padrão visual FinancePro.
- Testes unitários dos relatórios contabilísticos.

## Base de dados
Nenhum novo script é necessário. A versão utiliza as tabelas criadas por `019_AccountingEntryEngine.sql`.
