# FinancePro v2.3.0 — Dashboard Executivo

## Entrega

- Saudação dinâmica com o nome do utilizador autenticado.
- Atualização manual do painel e indicação da hora da última atualização.
- Cartão de disponibilidade total, somando caixa e contas bancárias.
- Ações rápidas ligadas aos módulos de Despesas, Orçamento, Tesouraria e Utilizadores.
- Tratamento de falhas durante o carregamento do dashboard.
- Correção da apresentação do exercício financeiro.
- Remoção de informação duplicada nos alertas.

## Base de dados

Esta versão não altera o modelo de dados e não exige migration.
