# FinancePro v3.2.0 — Cadastros Mestres Financeiros

## Entregas

- Serviços de aplicação para Bancos, Contas Bancárias e Moedas.
- Gateways desacoplados da persistência.
- Validação e normalização de SWIFT, IBAN, moeda, titular e saldo inicial.
- ViewModels de Bancos e Moedas integrados à camada Application.
- Testes unitários dos novos casos de uso.
- Sem alterações no modelo de dados; nenhuma migration necessária.
