# FinancePro v6.65.5 — Arredondamento superior dos cabeçalhos

## Alteração visual

- Os cabeçalhos de todas as tabelas passam a ter apenas os cantos superiores arredondados.
- Os cantos inferiores permanecem retos para assegurar continuidade com as linhas de dados.
- Continuam removidos os separadores verticais entre as colunas do cabeçalho.
- Estruturas, colunas, larguras, bindings e comportamentos permanecem intactos.

## Base de dados

Esta versão não requer migração nem alteração da base de dados.
