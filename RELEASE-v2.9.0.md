# FinancePro v2.9.0 — Património

## Incluído
- Camada Application para gestão patrimonial.
- Gateway de Património na camada Data.
- Integração do BemViewModel com AssetApplicationService.
- Validação centralizada para cadastro, edição e abate de bens.
- Preservação do histórico de auditoria e cálculo de depreciação existente.
- Testes unitários para criação, validação e abate.

## Base de dados
Nenhuma nova migration é necessária nesta versão.
