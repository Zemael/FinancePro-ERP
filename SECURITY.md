# Política de Segurança

Não publique vulnerabilidades, credenciais, connection strings reais ou dados pessoais em Issues públicas.

Relatórios de segurança devem ser enviados de forma privada ao proprietário do repositório. Inclua:

- versão afetada;
- descrição e impacto;
- passos de reprodução;
- eventual correção sugerida.

Segredos devem permanecer fora do Git. Use `appsettings.Local.json`, variáveis de ambiente ou GitHub Secrets.
