# FinancePro v4.0.0 — Dashboard Design System

## Escopo desta entrega

Primeira migração visual dos módulos para o padrão do Dashboard Executivo.

### Clientes
- Cabeçalho alinhado ao Dashboard, com atualização e novo registo.
- Indicadores de total, ativos, inativos e clientes com email.
- Pesquisa integrada.
- DataGrid moderno com estado e ações.
- Painel lateral de cadastro reorganizado.
- Data e hora da última atualização.

### Fornecedores
- Mesmo padrão visual e operacional aplicado ao módulo de fornecedores.
- Indicadores próprios e formulário independente.

### Design System
- Novos estilos reutilizáveis para KPI, textos auxiliares e campos de formulário.
- Base pronta para migração de Bancos, Caixa, Receitas, Despesas e Tesouraria.

## Base de dados

Nenhuma migration necessária.
