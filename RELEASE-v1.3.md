# FinancePro ERP v1.3 — Recebimentos

## Entrega

- Registo de contas a receber.
- Confirmação do recebimento para caixa ou conta bancária.
- Validação obrigatória de sessão aberta quando a origem é caixa.
- Validação de caixa/conta bancária ativa e pertencente à empresa.
- Transação atómica entre o movimento de Tesouraria e a atualização da conta a receber.
- Associação do cliente ao movimento financeiro.
- Data do recebimento selecionável.
- Mensagens de sucesso e erro na própria tela.
- Indicação visual quando uma caixa está indisponível por não possuir sessão aberta.

## Base de dados

Esta release não introduz nova tabela ou coluna. Se a migration da v1.2 já foi aplicada, não é necessário criar uma nova migration apenas para a v1.3.
