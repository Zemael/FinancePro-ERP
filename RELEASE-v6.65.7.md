# FinancePro v6.65.7 — Rodapé único e indicador de página compacto

## Correções visuais e funcionais

- Eliminada a duplicação de rodapés nos ecrãs Empresas, Exercícios Financeiros e Moedas.
- Mantido exclusivamente o rodapé global com contador e paginação funcional.
- As três tabelas utilizam agora as coleções completas, evitando paginação sobre dados já paginados.
- O cartão azul da página atual foi reduzido globalmente de 36×36 para 30×30 px.
- Os botões anterior e seguinte permanecem com 36×36 px, transparentes e sem bordas.
- Estruturas das colunas, bindings de seleção e ações permanecem preservados.

## Base de dados

Esta versão não requer migração nem alteração da base de dados.
