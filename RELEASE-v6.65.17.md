# FinancePro v6.65.17 — Distribuição vertical dos cartões

## Ajuste visual

- O conteúdo dos 55 cartões com ícone passa a usar três faixas verticais.
- Os títulos ficam posicionados no topo.
- Os valores ficam centralizados verticalmente e alinhados à esquerda.
- As legendas ficam posicionadas na base dos cartões.
- Mantidos os tamanhos de 11 px para títulos, 14 px para valores e 10 px para legendas.
- Os cartões antigos de Empresas, Exercícios Financeiros e Moedas que ainda definiam valores locais de 20 ou 22 px foram normalizados para 14 px.
- Mantida a redução automática dos valores extensos através do `Viewbox`.
- Preservados os ícones, bindings, comandos e estruturas funcionais.

## Base de dados

Esta versão não requer migração nem alteração da base de dados.
