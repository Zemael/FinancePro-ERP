# FinancePro v6.65.9 — CheckBox global moderno

## Alteração visual

- Todos os `CheckBox` do sistema passam a utilizar uma caixa de 22×22 px.
- Os cantos possuem raio de 6 px.
- Quando marcado, o controlo apresenta fundo azul sólido e check branco centralizado.
- Quando desmarcado, apresenta fundo transparente e borda cinza de 1,5 px.
- As mudanças de estado e o hover utilizam animações suaves de 120 ms.
- O cursor muda para ponteiro e a caixa recebe uma escala discreta ao passar o rato.
- Incluído tratamento visual para foco, estado desativado e estado indeterminado.
- O estilo alcança também os `CheckBox` gerados pelas colunas booleanas das tabelas.

## Base de dados

Esta versão não requer migração nem alteração da base de dados.
