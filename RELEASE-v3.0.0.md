# FinancePro v3.0.0 — UI Framework

## Objetivo
Criar uma base visual reutilizável para acelerar o desenvolvimento dos próximos módulos e manter consistência entre formulários, grelhas, barras de ferramentas e mensagens.

## Incluído
- Novo dicionário `FP.Components.xaml`.
- Estilos reutilizáveis para títulos, subtítulos, secções e rótulos.
- Cartões e barras de ferramentas padronizados.
- Botões primário, secundário, de perigo e de toolbar.
- Campos de texto, palavra-passe e seleção com altura e contraste consistentes.
- DataGrid padrão FinancePro.
- Mensagens de estado, sucesso e erro.
- Integração global em `App.xaml`.

## Base de dados
Nenhuma migration é necessária.
