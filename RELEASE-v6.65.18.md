# FinancePro v6.65.18 — Colunas da tabela de Permissões

## Ajuste visual

- A coluna Módulo mantém uma dimensão própria, com largura proporcional dupla e mínimo de 240 px.
- As colunas Consultar, Criar, Editar, Desativar, Aprovar, Exportar e Administrar passam a usar exatamente a mesma largura proporcional.
- Cada coluna de permissão possui largura mínima de 90 px para apresentar integralmente o cabeçalho e o `CheckBox`.
- A rolagem horizontal automática garante acesso a todas as colunas quando a janela disponível for mais estreita.
- Mantidos os bindings, estados e comandos da tabela.

## Base de dados

Esta versão não requer migração nem alteração da base de dados.
