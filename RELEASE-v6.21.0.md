# FinancePro v6.21.0 — Orçamento e Execução Orçamental

## Implementado
- Controlo mensal de previsto, comprometido, realizado e saldo disponível.
- Compromissos derivados de compras aprovadas/cotadas/com ordem emitida/recebidas ainda não faturadas.
- Percentual de execução efetiva e percentual de utilização incluindo compromissos.
- Alertas automáticos: execução controlada, próxima do limite ou orçamento excedido.
- Painel de controlo orçamental integrado à interface existente.
- Integração com Compras e movimentos financeiros sem duplicar valores realizados.
- Sem alteração de schema e sem nova migration.

## Validação
O XAML alterado foi validado estruturalmente. O build .NET final deve ser executado no ambiente Windows do projeto.
