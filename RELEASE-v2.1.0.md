# FinancePro ERP v2.1.0 — Administração Application Layer

## Entregue
- Casos de uso de Utilizadores, Perfis e Permissões na camada Application.
- Validação e retorno padronizado com Result/Result<T>.
- Portas de persistência independentes da UI e do Entity Framework.
- Adaptador Data para os serviços administrativos existentes.
- Registo dos serviços administrativos na injeção de dependência.
- Testes unitários para validações de utilizadores e perfis.

## Base de dados
Esta release não altera o modelo e não exige migration.
