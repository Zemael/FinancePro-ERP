# FinancePro v6.65.4 — Cabeçalhos de tabela sem separadores verticais

## Alteração visual

- Removidas as linhas verticais que dividiam as colunas dos cabeçalhos de todas as tabelas.
- Eliminados também os espaços entre células do cabeçalho para criar uma faixa visual contínua.
- Mantidas intactas as colunas, larguras, bindings, dados e funções de edição.
- As linhas horizontais entre os registos permanecem ativas.

## Base de dados

Esta versão não requer migração nem alteração da base de dados.
